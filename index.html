01 / THE PROBLEM

You remember the idea.
But where was it?

Revising a recorded lecture often means dragging a timeline, reading noisy auto-captions, and trying to find one explanation all over again.

Lecture Replay turns cleaned, timestamped transcripts into a study resource you can question. Its answers point back to the lecturer’s words, so you can check the context for yourself.

Designed to explain concepts and support revision.
Requests to complete graded work are declined.

Raw VTT captions are retained for audit. Rolling repetitions are removed while original word timestamps stay attached.

Apply glossary fixes, then use the LLM cleaning rules. Preserve uncertainty and verify timestamps before saving the notes.

clean_llm.py

Streamlit Q&A sends the available corpus to the model. The optional MCP route lets an agent retrieve passages with keyword tools.

answer.py / lecture_tools.py

Answers cite lecture and time. Known markers become video links; invalid timestamps are flagged instead of silently accepted.

06 / TRY IT YOURSELF

Your lecture assistant.
On your machine.

You’ll need Git and Python 3.10+. Run the commands from the project root. No API key is needed for the three cached demo questions.

01

Get the project

Clone the application repository. This is separate from the webpage you’re reading.

01 / GET THE PROJECT
git clone https://github.com/qpoe/AILT9019.git
cd AILT9019
02

Create an environment

Install the app dependencies in an isolated Python environment. Continue in the same terminal, inside the project folder.

Use your macOS or Linux terminal.

02 / CREATE AN ENVIRONMENT
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
03

Start & ask

With the environment still active, start the app, then open the Local URL shown in your terminal (usually http://localhost:8501). In the Ask tab, select a demo question. For new questions, add your own key in the API keys tab.

WHAT SUCCESS LOOKS LIKE

Ask. Inspect. Replay.

  1. Choose “How does a while loop work?” in the Ask tab.
  2. Without a key, see an answer labelled “cached demo answer”, with lecture citations.
  3. Open Lecture 3, 8:29 and verify the explanation in the recording.
Want live answers or the MCP route?

Live Streamlit answers: use the API keys tab to add and test your own provider key. The project supports OpenAI-compatible and Anthropic API formats. Keys stay in the local, git-ignored Streamlit secrets file.

MCP: install pip install -r requirements-mcp.txt inside the same environment. Configure your MCP client to launch the environment’s Python executable with the absolute path to mcp_server.py. It uses stdio and does not open a web port. Load the lecture-qa skill in the host agent; the host’s own model composes the answer.

Full Claude Code & skill walkthrough
Check the pipeline from your terminal

From the project root with the virtual environment active:

python answer.py "How does a while loop work?"
python answer.py "Solve this problem set question for me"
python check_note.py lecture1
python eval/evaluate.py --self-test

The first command uses a cached answer when no key is configured. The second should return mode: refused. Timestamp checks verify the cleaned note against the draft; the scorer self-test validates reference answers, not a fresh live model run.

To reproduce the full model evaluation with your configured key, run python eval/evaluate.py --generate --output eval/results.json. This replaces the local saved report.
